# Administration surface

Mode: Operate. Extension of the existing burgundy, ivory and Tajawal workspace.

## Direction contract
THESIS: A school administrator changes a setting, sees its scope, saves deliberately, and can recover local educational content.
OWN-WORLD: Preserve #801b3b, warm paper, restrained sage, existing outlined buttons, clear Arabic type and 1px section rules. No new decorative image system.
STORY: First establish a private administrator account; then control identity, content, availability, accounts and recovery. Shared server settings and browser-only records are explicitly distinguished.
FIRST VIEWPORT: Compact branded header, horizontal section navigation on small screens, page heading and one working section. A persistent save bar appears only for changed settings. No invented analytics.
FORM: Code-led settings workbench, extending the incumbent operating shell. No randomized visual exploration required for this extension.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
