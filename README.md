# تربية خاصة — مولّد الأنشطة التفاعلية

منصّة تساعد معلّمي التربية الخاصة على تحويل مادة تدريبية إلى **أنشطة تفاعلية** (أسئلة + ألعاب + تغذية راجعة) مناسبة تماماً لكل **فئة إعاقة**، مع **تقارير** لمتابعة تطوّر الطلاب.

الفئات المدعومة: التوحد · الإعاقة الذهنية · صعوبات التعلم · الإعاقة السمعية · الإعاقة البصرية · الإعاقة الحركية.

## التقنيات
- الواجهة: React + Vite + TypeScript + Tailwind (عربي RTL)
- الـ Backend والـ DB: Convex
- توليد المحتوى: Claude API (يُستدعى بأمان من Convex action)

## خطوات التشغيل

```bash
npm install
```

### 1) إعداد Convex (الـ Backend)
```bash
npx convex dev
```
أول مرة سيطلب تسجيل الدخول وإنشاء مشروع. بعد التشغيل سيطبع رابط الـ deployment.

### 2) ضبط المفاتيح
- انسخ `.env.local.example` إلى `.env.local` وضع فيه رابط Convex:
  ```
  VITE_CONVEX_URL=https://<your>.convex.cloud
  ```
- اضبط مفتاح Claude في Convex (لا يوضع في الواجهة أبداً):
  ```bash
  npx convex env set ANTHROPIC_API_KEY sk-ant-...
  ```

### 3) تشغيل الواجهة
```bash
npm run dev
```
أو شغّل الاثنين معاً:
```bash
npm run dev:all
```

## بنية المشروع
- `convex/` — المخطط والدوال (توليد، طلاب، جلسات/تقارير)
- `src/pages/` — الصفحات: الرئيسية، الفئات، توليد نشاط، اللعب، الطلاب، التقارير
- `src/categories.ts` — بيانات الفئات وقواعد تكييف الواجهة
