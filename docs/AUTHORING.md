# إنشاء العروض والتحضير بالذكاء الاصطناعي

إضافة 31 أكتوبر 2026 إلى مساحة تربية خاصة. الواجهة تتبع الهوية القائمة، وليست إعادة تصميم للمنصة.

## ما يمكن استخدامه الآن

من الدرس اختر «إنشاء PowerPoint»، أو افتح `/presentations`. الإنشاء من القالب يعمل محليًا دون مفتاح أو خدمة خارجية. تتكون الشرائح من الغلاف والهدف والتهيئة والمحتوى والتدريب والاستراحة والأسئلة والغلق. المصدر الطويل يُقسّم إلى شرائح دون حذف صامت؛ المصادر التي تتجاوز 16000 حرف أو 80 شريحة تحتاج تقسيمًا من المعلم قبل الإنشاء.

الموقع: تحرير النص والبدائل والإجابة، إضافة ونسخ ونقل وحذف مع تراجع، صور PNG/JPG محلية مع وصف بديل، ثلاثة أنماط (حديقة هادئة/هوية المنصة/وضوح عالٍ)، تكبير، معاينة، حفظ محلي واستعادة آخر مسودة. الحفظ يتوقف إذا تعذرت قراءة المكتبة لحماية بياناتها السابقة.

التطبيق: شاشة React Native لإنشاء القالب من درس، تعديل الشرائح والبدائل والملاحظات، إضافة شرح أو حذف ونقل، اختيار النمط وحجم النص، حفظ محلي وتصدير PPTX عبر نافذة مشاركة النظام. إضافة الصور ونسخ الشرائح متاحتان في الموقع في هذه الجولة. النص الأكبر يغيّر المعاينة أيضًا. تحذير الخروج يشمل رجوع النظام وgesture عبر `usePreventRemove` من Expo Router 58.

ملف PPTX يحتوي نصوصًا وأشكالًا قابلة للتحرير، واتجاه العربية ولغة النص، ووصف الصور، وملاحظات مستقلة للمعلم. الإجابات الصحيحة لا تُلوّن في شرائح الطلاب، وتوجد في ملاحظات المعلم. الأسئلة غير تفاعلية داخل PowerPoint؛ تُستخدم شفهيًا أو بالإشارة. الملف لا يحتوي مؤقّتًا أو انتقالًا تلقائيًا. يستعمل Arial لتقليل الاعتماد على توفر خط إضافي. قد تختلف المعاينة على الشاشة عن توزيع PowerPoint النهائي؛ راجع الملف في برنامج العرض قبل الحصة.

## تشغيل الذكاء الاصطناعي

يوجد مساعد في محرر التحضير لإنشاء الهدف والمراحل والتكييف والأسئلة، ومساعد في استوديو العروض لإنشاء 6/8/10/12 شريحة. يعرض الرد قبل تطبيقه، ولا يعتمد الدرس أو يغيّر أهداف الطلاب تلقائيًا. يُراجع مصدر الإرسال صراحة، ولا تُرسل ملفات الطلاب أو سجلاتهم أو بياناتهم التشخيصية تلقائيًا. مفاتيح إضافية غير مدرجة في قائمة الطلب المسموح بها لا تُمرر إلى المزوّد.

المزوّد المهيأ هو Claude توافقًا مع الربط الموجود في المشروع القديم. لا يوجد مفتاح محلي، ولم يجر اتصال توليد فعلي. نجاح الاختبار باستخدام رد خدمة مصطنع لا يعني أن حساب المزوّد مفعّل.

1. انسخ `.env.server.example` إلى `.env.server` في جذر هذا المشروع.
2. أضف `ANTHROPIC_API_KEY` واسم النموذج المتاح لحسابك في `ANTHROPIC_MODEL`. المثال الحالي `claude-sonnet-5-5` وفق [مرجع نماذج Claude](https://platform.claude.com/docs/en/models/overview).
3. أعد تشغيل `npm run dev -- --host 127.0.0.1 --port 5175`. يعمل المسار أيضًا مع `npm run preview` بعد البناء.
4. حالة الخدمة: `/api/author/status`. ظهور `ready` يعني وجود المفتاح فقط، ولا يتحقق من صلاحية الرصيد أو المفتاح حتى طلب التوليد.

المفتاح خادمي فقط، ولا يوضع في `VITE_*` أو `EXPO_PUBLIC_*` ولا في localStorage. `.env.server` مستبعد من Git. تتوقف الخدمة على الطلبات غير المحلية، وتفحص Origin وJSON وحجم الطلب، وتحدّ عدد الطلبات والتزامن، وتفرض مهلة اتصال، وتتحقق من صيغة المحتوى المستلم. لا تُسجّل نصوص الطلب أو ردود المزوّد الخام. هذه خدمة تجربة محلية، وليست بوابة عامة متعددة المدارس؛ نشرها يحتاج مصادقة وصلاحيات وحصص استخدام وخادمًا مناسبًا.

للتجربة في محاكي Android: `adb reverse tcp:5175 tcp:5175`، ثم إعداد `apps/mobile/.env.local` من `.env.example` وإعادة تشغيل Expo. عنوان API ليس مفتاحًا. هذه الإعدادات لا تجعل الخدمة متاحة عبر الإنترنت أو لكل هاتف فعلي؛ لا يوجد نشر خارجي ضمن هذا العمل. قوالب التطبيق وتصدير PPTX محليان ولا يحتاجان هذا الربط.

مرجع [Claude Messages API](https://platform.claude.com/docs/en/api/messages/create)، و[PptxGenJS](https://gitbrent.github.io/PptxGenJS/docs/quick-start/)، و[Expo FileSystem 58](https://docs.expo.dev/versions/v58.0.0/sdk/filesystem/)، و[Expo Sharing 58](https://docs.expo.dev/versions/v58.0.0/sdk/sharing/).
