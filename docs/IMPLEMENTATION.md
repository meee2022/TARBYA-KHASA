# النسخة الأولى — الموقع والتطبيق

تم تنفيذ مساحة عربية RTL لمعلم الدعم الإضافي، مع تطبيق مستقل بواجهات React Native وExpo Router. الاسم الحالي «تربية خاصة» مؤقت ويستمر في هوية المشروع العنابية.

## ما يعمل في النسخة المحلية

- لوحة عمل، قائمة دروس وبحث وحالات واضحة، مكتبة أمثلة قابلة للنسخ والتعديل.
- محرر تحضير بأربع خطوات: بيانات ومصدر، طلاب وأهداف، مراحل الحصة، أسئلة ومراجعة.
- ربط الأهداف بالمادة والطلاب؛ منع إرسال تحضير ناقص أو اعتماد تحضير لم يمر بالمراجعة؛ سبب مطلوب للإرجاع.
- ملفات افتراضية بنقاط قوة واحتياجات وتفضيلات وصول مستقلة، وإضافة أهداف وملفات من الموقع.
- نشاط اختيار قابل للتكييف، ببديلين أو ثلاثة، قراءة عربية/إنجليزية اختيارية، نص كبير وتباين أعلى.
- تسجيل الاستجابات الصحيحة والمستقلة والتلميحات؛ الاستجابة غير الملحوظة تُستبعد من مقام النتيجة، وتُحفظ المحاولات التفصيلية مع الملخص.
- متابعة لكل هدف وطباعة التحضير وأوراق الأسئلة والتقرير من المتصفح.
- قراءة النصوص من DOCX وPPTX وPDF وTXT على الجهاز، مع بيان أن الصور والصوت والفيديو وOCR غير مشمولة.
- واجهات أصلية للتطبيق: الصفحة الرئيسية، الدروس، المحرر، الطلاب وتفضيلاتهم، المراجعة، جلسة التعلم والنتائج. لا يحتوي التطبيق على WebView.

## البنية

الموقع القائم React/Vite في الجذر. التطبيق في `apps/mobile`. القواعد والبيانات المشتركة في `packages/domain/index.ts`. تخزين الموقع localStorage، وتخزين التطبيق AsyncStorage؛ كل جهاز مستقل حاليًا. لم تُنشر تغييرات على قاعدة Convex القديمة ولم تُنقل إليها البيانات التجريبية الجديدة.

الكود السابق محفوظ في `src/LegacyApp.tsx` وصفحاته الأصلية. مصدر ملفات المعلمة باقٍ في الجذر ولم يُنشر في مجلد public. جميع الطلاب في النسخة الجديدة افتراضيون. الرسمة التعليمية أُنشئت للمشروع، وسجل منشئها وتعليماتها بجوار الصورة.

## ما لم يُنجز بعد

هذه بداية تنفيذ قابلة للتجربة المحلية، وليست منصة مدرسة منشورة. يحتاج الإطلاق إلى حسابات موثقة وصلاحيات خادم وعزل المدارس، مزامنة الموقع والتطبيق، تخزين خاص للمصادر، نسخ احتياطي واستعادة، ومراجعة المحتوى التربوي. زر المراجعة يحاكي سير العمل محليًا؛ لا يمثل اعتمادًا رسميًا أو حماية حسابات.

محرر التحضير يستخدم قالبًا قابلًا للتعديل، وأضيف إليه مساعد لإنشاء مسودة عبر Claude. الربط موجود ويحتاج مفتاح خادم لتشغيل التوليد الفعلي؛ راجع AUTHORING.md. استيراد الملفات في الموقع فقط، دون OCR أو استخراج الوسائط. أضيفت مساحة ألعاب للمطابقة والتصنيف والتسلسل وبرايل في الموقع والتطبيق، مع لوحة تواصل وتفضيلات وصول. التفاصيل وحدود الاختبار في ACCESSIBILITY.md. لا توجد تغطية كاملة لأي منهج ولا استنتاج آلي لتحقق الهدف من جلسة واحدة.

## التحقق

- نجحت اختبارات القواعد المشتركة الستة، بما فيها استبعاد المحاولات غير الملحوظة وفصل المساعدة عن الاستقلالية.
- نجح بناء الموقع باستخدام TypeScript وVite.
- نجح فحص TypeScript للتطبيق وExpo lint، وتصدير حزمة Android عبر Metro.
- عُرضت الرئيسية على الكمبيوتر وعرض 390×844؛ أُجريت تحسينات للنصوص وتخطيط صفوف الدروس.
- توقفت أداة Computer Use لاحقًا تلقائيًا لعدم القدرة على تحديد عنوان المتصفح الحالي على Windows. لم تُستكمل إعادة التصوير بعد التحسينات ولا الاختبارات التفاعلية من البداية للنهاية. مراجعة Impeccable النهائية: `recapture`، وليست موافقة بصرية نهائية.
- لم يُتحقق من iOS أو أجهزة فعلية. نجاح حزمة JavaScript لا يساوي نجاح APK أو مراجعة واجهة أصلية على الجهاز.

## التشغيل

الموقع: `npm install` ثم `npm run dev -- --host 127.0.0.1 --port 5175`.

التطبيق: داخل `apps/mobile`، شغّل `npm install` ثم `npx expo start`. للبناء المحلي مع Android SDK وJava: `npx expo run:android`. ملف `eas.json` جاهز لملفات development/preview/production، ويتطلب حساب البناء وإعداد التوقيع عند استخدام EAS. لم يتم رفع المشروع إلى خدمة بناء خارجية.

التحقق: `npm test` و`npm run build` في الجذر، و`npm run typecheck` و`npm run lint` داخل التطبيق.
